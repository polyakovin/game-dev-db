# Code of Conduct

Game Dev DB welcomes contributors with different backgrounds and levels of experience. These rules apply to repository issues, pull requests, reviews, and other project spaces.

- Discuss ideas and implementation choices with evidence and respect.
- Help beginners understand the next useful step. Questions and mistakes are part of learning.
- Criticize work without attacking the person who made it.
- Respect privacy. Do not share someone else's personal information or private communications.
- Do not harass, threaten, discriminate, spam, or publish sexual content in project discussions.

Maintainers may edit or remove inappropriate content, close a discussion, limit participation, or block repeated or serious violations. Their response should be proportionate to the behavior and its impact.

Report a concern to a maintainer through an available GitHub contact channel. Do not post sensitive details publicly. If no private channel is listed, ask for one without identifying affected people or describing private events.

## По-русски

Обсуждайте решения по существу и уважайте участников независимо от опыта. Помогайте новичкам, спокойно исправляйте ошибки и не переходите на личности. Травля, угрозы, дискриминация, спам и раскрытие чужих персональных данных недопустимы.

Мейнтейнеры могут удалять нарушающий правила контент и ограничивать участие. Для сообщения о нарушении используйте доступный контакт мейнтейнера; если личного канала нет, попросите его без публикации чувствительных подробностей.
