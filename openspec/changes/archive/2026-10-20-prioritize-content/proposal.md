# Proposal

## Why

Most catalog lists inherit import or file order, so incidental details can precede the concepts needed to design a playable prototype. Readers need a consistent editorial order within every section and subsection, in both languages.

## What Changes

- Put foundational, widely useful topics before specialized techniques in lesson categories, mechanic catalogs and their trees, lens themes, practice topics and reference groups.
- Rank entries within those groups by their value for understanding and testing a small game.
- Share ordering between static HTML, navigation/filter options, JSON and Markdown exports, preserving all identities, links, source attribution and authored procedural sequences.
- Keep jam events ordered by actionable deadlines; rank discovery calendars by breadth and usefulness.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `knowledge-portal`: editorial ordering across catalogs and nested content, with equivalent localized exports.

## Impact

A shared editorial ordering module and configuration, catalog localization, resource grouping, lesson selection, content validation, browser regression checks and an ordering guide. No new dependency, route or v1 field is required. Existing working-copy changes remain outside this task.
