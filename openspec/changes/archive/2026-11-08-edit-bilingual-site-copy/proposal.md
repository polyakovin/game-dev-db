## Why

Some passages open with a slogan or a stock contrast before telling the reader what a mechanic does or how to check it. The English catalogs also contain literal translations that obscure familiar game-design terms.

## What Changes

- Review Russian and English site introductions, lesson prose, and recurring catalog copy using Humanizer.
- Preserve the meaning of each language pair, including examples, limits and attribution.
- Edit the authored sources so the revised wording reaches HTML, search, Markdown and JSON.
- Record the Humanizer workflow for future public prose in `AGENTS.md`.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `knowledge-portal`: preserve the instructional and export contract during editorial revisions.

## Impact

The change touches public prose and the project introduction. Identifiers, headings used for navigation, lesson frontmatter, code examples, URLs, data schemas and publication behavior retain their existing contract.
