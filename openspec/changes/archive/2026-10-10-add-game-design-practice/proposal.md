# Add a game design practice section

## Why

Readers need a small, concrete exercise after studying game-design principles.
Publish twelve original exercises around the broad learning topics of Brenda
Brathwaite and Ian Schreiber's _Challenges for Game Designers_. Use independently
written scenarios, constraints, outputs and checks, with explicit attribution to
the thematic inspiration rather than presenting the collection as a translation.

## What Changes

- Add a bilingual `/practice/` section with complete native disclosures, combined
  search/topic/duration filters, reset and stable exercise anchors.
- Add navigation and home-page discovery using the existing visual system.
- Use one bilingual JSON content source for static HTML, versioned JSON,
  Markdown, manifest, agent discovery and full corpus.
- Preserve existing lessons, mechanics, `/api/v1/` fields and base-path behavior.

## Validation

Validate source completeness and translation alignment, built exports, both
languages, keyboard interaction, narrow layouts and reading without JavaScript.
Run canonical verification and browser checks before GitHub Pages publication.

## Exclusions

No accounts, saved completion state, submission service or copied book exercises.
