# Proposal

## Why

Readers need to understand one mechanic at a glance. The existing focused pages repeat long taxonomy sections and lack an illustrated example, so they do not meet the requested single-screen format.

## What Changes

- Pilot the format on the shared Search and discovery mechanic, in Russian and English.
- Show a short definition, a real annotated Hidden Folks screenshot with source credit, concise application advice and example links.
- Keep one canonical page for both children and education placements; make the pilot directly discoverable from each catalog.
- Keep the complete existing taxonomy and exports compatible; expose the compact content additively through the common record.
- Fit the default desktop and phone presentation within one viewport without clipping or internal scrolling. Preserve readable document flow when text is enlarged or space is unusually constrained.
- Leave all other mechanics in their existing format until the user reviews the pilot.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `search-discovery`: allow an authored compact mechanic presentation at the existing canonical URL while retaining full machine formats and catalog detail.

## Impact

Focused page rendering, optional compact layout, bilingual pilot data, shared record attributes, catalog links, screenshot attribution, documentation and browser checks. No new runtime service or dependency.
