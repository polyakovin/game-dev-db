## Why

In the smallest windows, controls, categories and image captions crowd out the
mechanic illustration. The reader needs only the title, short definition and
annotated screenshot at that size.

## What Changes

- Add a minimal pilot layout for short, small windows, hiding page chrome,
  categories, captions, advice, examples and footer.
- Float the illustration beside the definition in very narrow, short windows;
  keep a larger image below or beside text when the proportions permit.
- Preserve localized marker tooltips, the full layout at larger sizes, and all
  source/attribution metadata and machine exports.

## Capabilities

### Modified Capabilities
- `search-discovery`: viewport-dependent compact mechanic presentation.

## Impact

Only the existing RU/EN mechanic pilot presentation, layout rules, browser checks
and documentation change. IDs, routes, content and v1 exports remain compatible.
