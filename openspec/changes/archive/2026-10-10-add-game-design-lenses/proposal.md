# Add game-design lenses

## Why
Readers need the complete set of perspectives in the maintainer's Schell notes, plus verified additions, as a usable review tool alongside the mechanic catalogs.

## What Changes
- Add a dedicated bilingual Lenses section with 113 Schell perspectives from the supplied second-edition notes, three third-edition additions and Deterding's separately attributed intrinsic skill atoms lens.
- Provide original concise explanations and review questions, stable anchors, theme/source filters and author/source context. Do not publish copied book passages or exercises.
- Generate HTML, JSON and Markdown from one bilingual dataset and expose it additively through the v1 manifest, agent indexes and sitemap.
- Validate identities, coverage, translations and source references; check search, keyboard disclosures, mobile layouts and reading without JavaScript.

## Capabilities
### New Capabilities
- `game-design-lenses`: attributed bilingual game-design perspectives and compatible machine exports.

### Modified Capabilities
None.

## Impact
New source data, renderer, search, exports and tests; small navigation, home, manifest, discovery and documentation additions. Existing lesson, resource and mechanic interfaces remain compatible.
