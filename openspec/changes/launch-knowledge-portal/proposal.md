# Launch Game Dev DB

## Why

Developers working with AI need a small, understandable reference for game-development
principles. Humans need readable lessons; agents need addressable, structured sources.
The owner explicitly requested a bilingual open-source MVP and GitHub Pages publication.

## What Changes

- Publish an accessible Russian/English catalog, searchable lessons, resources and agent guide.
- Seed eight original lesson pairs with sources, examples, pitfalls and checks.
- Generate versioned JSON, individual Markdown exports and llms discovery files.
- Establish OpenSpec, contributor documentation, licenses and automated release checks.
- Deploy verified static output through GitHub Actions to GitHub Pages.

## Capabilities

### New Capabilities
- `knowledge-portal`: localized human reading and structured agent access to one content source.

### Modified Capabilities
None.

## Impact

Adds Astro, a Markdown content contract and GitHub Pages workflow. No backend, accounts,
analytics, payment integration or paid hosting. Commercial template data remains pending;
the new project scope supersedes its product-implementation gate by explicit owner request.
