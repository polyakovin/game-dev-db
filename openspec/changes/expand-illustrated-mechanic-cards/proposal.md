## Why

The reviewed single-screen mechanic pilot should become the presentation for
every active canonical mechanic. The current library contains 1268 active
records, including concrete techniques and broader directions, but only one has
an authored illustrated card. Work should start with broadly reusable actions
and systems rather than rare variants.

## What Changes

- Maintain an exhaustive, stable editorial production order for active canonical
  mechanics. Priority reflects cross-genre usefulness, not measured popularity.
- Author concise RU/EN titles and definitions, real-game screenshots, contextual
  numbered tooltips, brief advice and primary example links.
- Validate local image dimensions, crops, marker placement, source attribution,
  complete localization and canonical coverage before enabling each card.
- Reuse the reviewed compact/minimal responsive layouts and existing stable URLs.
- Publish verified groups in priority order while retaining full reference
  sections and machine exports. Do not mark unsourced illustrations complete.

## Capabilities

### Modified Capabilities
- `search-discovery`: compact illustrated mechanic cards and production priority.
- `mechanics-reference`: shared discovery of authored cards from all placements.

## Impact

Presentation data, source images, compact component, content validation,
discovery, tests and documentation. New metadata is additive to v1; authored
taxonomy identities, archived records and collection anchors remain compatible.
